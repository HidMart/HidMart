نصب

آخرین نسخه:

pip install hidmart

نصب نسخه 0.3.0:

pip install hidmart==0.3.0

نسخه 0.3.0 به Python 3.9 یا بالاتر نیاز دارد.

شروع سریع

from hidmart import Bot

bot = Bot("TOKEN")

@bot.on_command("start")
async def start(message):

await message.reply(
    "سلام 👋\nHidMart 0.3.0 فعال است."
)

bot.run()
