نصب

آخرین نسخه:

pip install hidmart

نصب نسخه 0.4.0:

pip install hidmart==0.4.0

HidMart 0.4.0 به Python 3.9 یا بالاتر نیاز دارد.

شروع سریع

from hidmart import Bot

bot = Bot("TOKEN")

@bot.on_command("start")
async def start(message):

    await message.reply(
        "سلام!\nHidMart 0.4.0 فعال است."
    )

bot.run()

Bot

ساخت Bot

bot = Bot("TOKEN")

تنظیمات

bot = Bot(
    "TOKEN",
    poll_interval=1.0,
    timeout=25
)

اجرای Bot

bot.run()

اجرای Async

await bot.start()

توقف

await bot.stop()

async def photo_handler(message):

    photo = message.photo[-1]

    file_id = photo["file_id"]

    await bot.send_photo(
        message.chat.id,
        file_id,
        caption="عکس دریافت و دوباره ارسال شد."
    )

Keyboard

در نسخه 0.4.0 ساخت کیبوردهای مختلف برای ربات اضافه شده است.

InlineKeyboard

from hidmart.ui import InlineKeyboard

keyboard = InlineKeyboard()

keyboard.add_button(
    "گزینه ۱",
    callback_data="option_1"
)

keyboard.add_button(
    "گزینه ۲",
    callback_data="option_2"
)

await message.reply(
    "یک گزینه انتخاب کنید:",
    reply_markup=keyboard.to_dict()
)

ساخت چند دکمه در یک ردیف

from hidmart.ui import (
    InlineKeyboard,
    InlineButton
)

keyboard = InlineKeyboard()

keyboard.row(
    InlineButton(
        "گزینه ۱",
        callback_data="one"
    ),
    InlineButton(
        "گزینه ۲",
        callback_data="two"
    )
)

await message.reply(
    "انتخاب کنید:",
    reply_markup=keyboard.to_dict()
)

ساخت Keyboard با rows

Buttons

InlineButton

from hidmart.ui import InlineButton

button = InlineButton(
    "کلیک کنید",

Callback Button

button = InlineButton(
    "دکمه",
    callback_data="my_callback"
)

با کلیک روی این نوع دکمه، مقدار callback_data برای پردازش Callback استفاده می‌شود.

URL Button

button = InlineButton(
    "باز کردن سایت",
    url="https://example.com"
)
callback_data و url نمی‌توانند هم‌زمان برای یک InlineButton استفاده شوند.

مدیریت خطاها

خطاهای اصلی HidMart:

  • HidMartError
  • APIError
  • NetworkError
  • InvalidTokenError

Import

from hidmart import (
    HidMartError,
    APIError,
    NetworkError,
    InvalidTokenError
)

استفاده

try:

    await bot.send_message(
        chat_id,
        "Hello"
    )

except InvalidTokenError:

    print("Invalid Token")
